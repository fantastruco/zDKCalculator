Adds application updates through Settings.

- Check the latest public Windows release without signing in.
- Download and verify updates before installing and restarting.
- Preserve presets, settings and saved sessions during updates.
- Add public-source CI builds and portable release packaging.

Download `DokkanDefenseCalculator-Windows-x64.zip` for the portable application and documentation, or `DokkanDefenseCalculator.exe` for the standalone executable. Requires Windows 10 or 11, 64-bit.
