Adds configurable attack sequences and DEF progression within a turn.

- Open Info → Turn to configure an opening attack and ordered additionals.
- Choose Normal Attack, Super Attack or Ultra Super Attack for each entry, with reorder and remove controls.
- View starting DEF, DEF after each attack, DEF gained and incoming-damage details.
- Configure passive DEF build-up per attack, per Super Attack or per Ultra Super Attack, including previous activations and a cap.
- Use the final planned DEF in Damage and Calcs when After attack is selected.
- Save attack plans and build-up settings in unit presets and sessions while retaining legacy-file support.

New SA/Ultra effects start with zero active raises. Enter previous raises in Unit Effects; the turn preview adds the new matching attacks. Each calculation stage continues to truncate to an integer.

Download `DokkanDefenseCalculator-Windows-x64.zip` for the portable application and documentation, or `DokkanDefenseCalculator.exe` for the standalone executable. Requires Windows 10 or 11, 64-bit.
